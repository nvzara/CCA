# 치이카와 자격검정소 (ちいかわ検定所)

나가노 선생님의 만화 『치이카와 — 먼가 작고 귀여운 녀석』 세계에 등장하는 자격시험을 직접 응시하고, 합격하면 자격증을 발급받을 수 있는 **비공식·비영리 팬 사이트**입니다.

> 작고 귀여워도, 시험은 진짜입니다.

## 시험 종목

| 종목 | 등급 | 검정 방법 |
|---|---|---|
| 풀뽑기 검정 (草むしり検定) | 5급 ~ 1급 | 필기 + 실기(풀뽑기 작업형) |
| 술 자격증 (お酒の資格) | 단일등급 | 필기 + 안전 음용 서약 (만 19세 이상) |
| 슈퍼 알바이터 (スーパーアルバイター) | 단일등급 | 필기 + 실기(라멘 로우 콜 응대) |

## 기능

- **수험자 등록** — 부위를 골라 그리는 증명사진
- **원서 접수** — 응시자격 확인(하위 등급 취득, 나이, 필기 합격 유효기간), 시험장 선택, 가상 납부, 수험표 인쇄
- **필기시험** — 시험지(문제지)와 답안지를 따로 쓰는 지필 방식. 답안지에 마킹한 답만 채점하며, 과목별 과락과 평균 합격선을 적용
- **실기시험** — 공구 선택·위험초 확산·위험 생물 경보가 있는 풀뽑기 작업장, 식권 확인부터 콜 해석까지 하는 라멘 주방
- **합격자 발표 · 자격증 발급 · 진위 확인** — 카드형/증서형 자격증, 검증문자가 들어간 자격번호, 재발급 시 기존 자격증 효력 상실
- **공개문제** — 출제 범위에서 무작위 10문항, 정답과 해설 제공
- **운영규정 · 라멘 로우 콜 매뉴얼 · 게시판 · 자주 묻는 질문**

문제는 실제 원예·잡초 방제, 주류·보건·법규, 식품위생·근로기준법 지식과 사이트의 운영규정을 바탕으로 출제됩니다.

## 실행

빌드 과정이 없는 정적 사이트입니다.

```bash
python3 -m http.server 8000
# http://localhost:8000 접속
```

GitHub Pages에서는 저장소 루트를 그대로 배포합니다.

## 구조

```
index.html
assets/
  css/style.css
  js/
    util.js        공통 함수, 증명사진·장식 그림
    store.js       브라우저 저장소(localStorage)
    exam.js        필기시험(시험지·답안지)
    practical.js   실기시험(풀뽑기, 라멘 로우)
    license.js     자격증 그리기
    app.js         화면과 라우팅
    data/
      certs.js     종목, 운영규정, 콜 매뉴얼, 게시글
      q-weed.js    풀뽑기 검정 문제은행
      q-sake.js    술 자격증 문제은행
      q-alba.js    슈퍼 알바이터 문제은행
```

모든 기록은 이용자의 브라우저에만 저장되며 서버로 전송되지 않습니다.

## 안내

- 원작자 및 공식 권리자와 관계없는 비공식 팬 사이트이며, 어떠한 이윤도 추구하지 않습니다.
- 캐릭터·명칭·세계관에 관한 모든 권리는 원작자와 공식 권리자께 있습니다. 공식 이미지는 사용하지 않았고, 사이트의 그림은 모두 직접 그렸습니다.
- 원작에서 공개되지 않은 시험 과목, 문제, 합격 기준, 운영규정 등은 팬의 상상으로 채운 것으로 공식 설정이 아닙니다.
- 발급되는 자격증은 재미를 위한 것으로 법적 효력이 없습니다.
- 권리자께서 우려를 표하시면 즉시 수정하거나 운영을 중단하겠습니다.
