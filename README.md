# 치이카와 자격검정소 (ちいかわ検定所)

나가노 선생님의 만화 『치이카와 — 먼가 작고 귀여운 녀석』 세계에 나오는 자격증에, 치이카와들처럼 우리도 도전해 보는 **비공식·비영리 팬 사이트**입니다.

https://nvzara.github.io/CCA/

## 도전할 수 있는 자격

| 종목 | 등급 |
|---|---|
| 풀뽑기 검정 (草むしり検定) | 5급 ~ 1급 |
| 술 자격증 (お酒の資格) | 단일등급 · 만 19세 이상 |
| 슈퍼 알바이터 (スーパーアルバイター) | 단일등급 |

수험자 등록, 원서 접수, 수험표, 시험, 합격 발표, 검정증 발급과 진위 확인까지 검정소에서 할 수 있는 일은 다 해 볼 수 있어요. 어떤 시험인지는 직접 확인해 주세요.

그 밖에 고서점 퀴즈, 오늘의 수험 운세, 작중 합격자 명부, 노동 게시판, 상영실(공식 영상), 응원 박수가 있어요.

## 실행

빌드 과정이 없는 정적 사이트입니다.

```bash
python3 -m http.server 8000
# http://localhost:8000 접속
```

GitHub Pages에서는 저장소 루트를 그대로 배포합니다.

## 구조

```
index.html
assets/
  css/style.css
  img/           공유 미리보기 이미지, 링크 배너
  js/
    util.js        공통 함수, 캐릭터·장식 그림
    store.js       브라우저 저장소(localStorage)
    exam.js        필기시험
    practical.js   실기시험
    license.js     검정증 그리기
    app.js         화면과 라우팅
    data/
      certs.js     종목, 운영규정, 콜 매뉴얼, 게시글
      fan.js       퀴즈, 운세, 합격자 명부, 갱신 기록
      q-*.js       문제은행
```

모든 기록은 이용자의 브라우저에만 저장되며 서버로 전송되지 않습니다.

## 안내

- 원작자 및 공식 권리자와 관계없는 비공식 팬 사이트이며, 어떠한 이윤도 추구하지 않습니다.
- 캐릭터·명칭·세계관에 관한 모든 권리는 원작자와 공식 권리자께 있습니다. 사이트의 그림은 모두 팬이 직접 그렸고, 공식 이미지를 내려받아 쓰지 않습니다.
- 공식 영상·게시물은 YouTube·X의 공식 임베드로, 이용자가 누를 때만 원본 그대로 불러옵니다.
- 원작에서 공개되지 않은 시험 과목, 문제, 합격 기준, 운영규정 등은 팬의 상상으로 채운 것으로 공식 설정이 아닙니다.
- 발급되는 검정증은 재미를 위한 것으로 법적 효력이 없습니다.
- 권리자께서 우려를 표하시면 즉시 수정하거나 운영을 중단하겠습니다.
